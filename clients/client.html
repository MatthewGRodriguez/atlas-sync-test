Sign in with GitHub (personal access token)

Each person writes only to their own public repo <your-login>/atlas-sync-log and reads everyone else's without a token. Never hand your token to someone else, and never ask for theirs. A fine-grained token can only write to repos owned by the token's own account (being a collaborator does not help).

opens GitHub's token page in this tab; after generating the token, use your browser's Back button to return here and paste it
  1. Easiest: first create your repo with Create my log repo below (no token needed), then make the token.
  2. On the token page, under Repository access pick Only select repositories → <your-login>/atlas-sync-log (or All repositories if you ticked the create option, since a repo that does not exist yet cannot be selected).
  3. Under Permissions confirm Contents: Read and write (prefilled). Click Generate token, copy it, press Back, paste it below.

The token stays in this tab's memory only (or sessionStorage if you tick "Remember for this tab"). It is never written to localStorage, the repo, the log, or the diagnostics. This is a pasted token: GitHub offers no sign-in for a static page without a backend.
