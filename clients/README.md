# clients/

`client.html`: a single-file test client used by every writer (`?writer=A`, `?writer=B`). It signs in with a pasted fine-grained personal access token (the button navigates the same tab to GitHub's prefilled token page, then you press Back to return and paste; GitHub offers no static-page sign-in without a backend), keeps the token only in the tab (memory, optionally sessionStorage), writes one log segment per accepted batch to `log/<writer>/<seq>.json`, and polls `main` for the other writers' segments. Codec hooks: `encodeSegment/decodeSegment/encodeSnapshot/decodeSnapshot`. See `../docs/test-runbook.md`.
